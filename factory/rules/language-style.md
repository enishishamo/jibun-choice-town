# JIBUN CHOICE LANGUAGE STYLE GUIDE（v1・2026-09-03）

根拠: factory/state/expansion/language-research.json（実在17タイトルの表記・文章運用研究。
Pokémon HGSS以降の表記モード、あつ森/Splatoon3/DQXI S/ゼルダ/レイトンの選択的ルビ、
妖怪ウォッチ/パズドラクロスの広汎ルビ、ScratchJr/トドさんすう等の文字非依存設計）。

対象: Primary=小学校高学年〜中学生。Secondary=より低年齢が自力で触る可能性。
方針: **対象年齢を下げない。全部ひらがなにしない。** 高学年が自力で読め、中学生が幼稚に
感じず、低学年は絵・動き・ふりがな・短い補助である程度触れる。

## 1. 漢字
- 本文は**小学校配当漢字（〜小6）を原則そのまま使う**。ひらがなに開きすぎない
  （妖怪ウォッチ級に開くのは低学年向けであり、中学生が幼く感じる）。
- 中学配当・難読・特殊読み・初出固有名詞は使ってよいが、**必ずルビ（§2）を付ける**。
- 見出し・ボタンでは、同じ語でも画数の重い表記より読みやすい表記を優先
  （例:「戻る」OK、「遡る」→「さかのぼる」）。

## 2. ふりがな（ルビ）
- 方式: **選択的ルビ**（あつ森/ゼルダ型）。全漢字一律ルビはしない（画面が幼くなる・
  密度が上がる）。
- 付ける対象: (a) 中学配当以上の漢字 (b) 特殊読み（保定=ほてい 等）
  (c) 職業の専門語（§3）の初出 (d) 固有名詞の初出。
- 頻度: **画面（スクロール単位）ごとに初出1回**。同一画面内の2回目以降は省略可。
  別画面へ移ったら再表示。
- 実装: `<ruby>保定<rt>ほてい</rt></ruby>`。データ側は `｜保定《ほてい》` 記法を許可し、
  表示層で ruby へ変換（`src/lib/ruby.tsx` の `withRuby()`）。
- ルビを除いた本文は16px相当以上・主要ボタン18px相当以上。ルビで行間・ボタンが崩れないこと。

## 3. 専門語（この製品の価値の一部。安易に消さない）
- 悪い例: 専門語→幼児語へ全置換。良い例: **専門語＋短い言い換え（15〜30字）＋視覚的理解**。
  例:「｜保定《ほてい》（動物をおさえて動けなくすること）」＋保定シーンの絵/アイコン。
- 新しい専門語は**1画面につき1語まで**。導入直後の課題でその語を実際に使わせる。
- 職業固有の言い回し（セリ、日量表、差圧、間伐 など）は残す。出会い自体が価値。

## 4. 文章
- 1文 ≤ **45全角文字**（会話体は22字/行×3行以内を目安）。
- 1画面の連続説明は**最大2ブロック**。その後は必ず操作（タップ/選択/確認）を挟む。
- 説明blockは4行を超えない。超える内容は「くわしく」の任意展開（InfoCards）へ。
- 改行は意味の切れ目で。読点の多い長文より、文を割る。
- 語りかけ調（〜だよ/〜しよう）は低学年向けに寄せすぎない。中学生も読める
  「〜だ。/〜する。」と混ぜ、感嘆符を乱用しない（1画面1個まで）。

## 5. ボタン
- **2〜6文字**、行動が分かる動詞（「選ぶ」「つぎへ」「見なおす」「町へもどる」）。
- 説明文ボタン禁止（「〜してみよう！」等の文はラベルでなくリード文へ）。
- OK/はい だけのボタン禁止（何が起きるかをラベルに）。

## 6. Failure / Hint（Experience Gateと整合）
- 失敗文は答え・規則・見るべき資料名を漏らさない。世界の反応（首を振る・❗・状態変化）が第一。
- 段階: 1回目=視覚的結果のみ → 2回目=「何か見落としているかも」級の汎用 → それ以上で具体。
- 失敗画面の教訓文は「方法論の一般論」まで（正解の特定はしない）。

## 7. Middle-school Fit（幼稚化の禁止）
- 禁止: 全文ひらがな、赤ちゃん語（〜でちゅ等）、過剰な「！」「♪」、全語への絵文字添付、
  「おともだち」等の低学年語彙で中学生に語りかけること。
- 職業世界の緊張感（締切・予算・安全）は薄めない。難しさはUI・視覚・ルビで支える。

## 8. VISUAL-FIRST（§6）
優先順位: **絵 → 動き → world state → 短い言葉**。
「文章を読まないと何をすればいいか一切わからない」画面は LANGUAGE QA FAIL。
目的は常に「目的カード＋対象の視覚強調＋短い操作ラベル」の三重化で伝える。

## 9. Language QA Gate（§5・fail-closed）
新規world/画面のレビューで以下を採点（Codex独立レビュー）:
- LANGUAGE_AGE_FIT（高学年自力読解×中学生非幼稚）**≥80必須**
- BUTTON_CLARITY **≥80必須**
- TEXT_DENSITY **≥80必須**
- FURIGANA_SUPPORT / TECHNICAL_TERM_SUPPORT / VISUAL_LANGUAGE_SUPPORT ≥70
- 文章なしでは操作不能な画面がある場合 VISUAL_LANGUAGE_SUPPORT = FAIL
- BLOCKER/HIGH = 0 で PASS。
既存worldは今回全修正しない。LANGUAGE_BACKLOG（factory/state/expansion/language-backlog.json）
に記録し、新規worldは本ガイドを最初から適用する。
