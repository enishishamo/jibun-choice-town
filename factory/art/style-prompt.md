# JIBUN CHOICE 共通スタイルプロンプト（シリーズ正本）

`art-generate.mjs` は、各 manifest の `common_style`（ワールドごとの調整済みスタイル文）を
全画像のプロンプト先頭に自動で挿入する。manifest に `common_style` が無い場合は、
このファイルの「STYLE BLOCK」がフォールバックとして使われる。

ワールド固有の味付けは manifest 側の `common_style` を編集する。
シリーズ全体の基準を変えるときだけ、このファイルと `factory/rules/art-style.md` を
同時に更新すること（食い違い禁止）。

## STYLE BLOCK

丸みのある3Dクレイ（粘土細工）風のミニチュア・ジオラマ。手作り感のある柔らかい
質感、明るくあたたかい配色。対象は小学4〜6年生（幼児向けにしない。少し大人っぽく
おしゃれに）。写実CGに寄せない。シリーズ全体で同じ粘土の素材感・同じ光（柔らかい
斜光）に揃える。画像内に読める文字・数字・ロゴ・透かしを一切入れない。

## 全画像共通の禁止事項（スクリプトが必ず末尾に付加する）

- 読める文字・数字・アルファベット・看板の文言
- 実在ブランド・実在人物に似た顔
- 写実的な質感、過剰な汚れ・恐怖表現
