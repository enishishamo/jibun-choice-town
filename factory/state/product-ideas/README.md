# Product Ideas（Human Product Decision待ち）

`factory/rules/product-identity-gate.md` に基づき、Product Identity Gateの
対象カテゴリ（brand character/mascot、core gameplay loop、collection/育成
system、reward economy、engagement system、子どもの分類system、Homeの
major feature、主要navigation architecture、世界観・ブランドidentity、
Mission/target age/core philosophy、monetization組み込み等）に触れる
アイデアをここに記録する。

通常のDevelopment Backlog（`factory/state/backlog/*.md`）とは別枠。
ここにあるものは **採用決定ではない**。すべて `DESIGN_RESERVED` /
`HUMAN_EXPLORATION_REQUIRED` として扱い、AIは実装しない。

## ファイル

- `gate-log.md` — Product Identity Gateが発火した記録（proposed_change /
  why_ai_considered_it / affected_core_assumption / options /
  recommendation / HUMAN_PRODUCT_DECISION_REQUIRED）
- `idea-*.md` — 個別のPRODUCT_IDEA
