## 1. 現Homeが「子ども向け」に見えない原因（重要度順・5つ以内）

1. **背景が世界を隠している。** Continuous Worldを`blur(11px)`＋上部から`transparent`へフェードするマスクで、鮮やかなclay diorama画像を淡いクリーム色の靄へ変換している。флyerなら彩度の高いフラットな色面か、ぼかさない一枚絵を使う。ここでは「世界を覗く」ではなく「世界を薄めて隠す」処理になっている。
2. **画面の中で「JC世界」に見えるのは主カード1枚だけ。** ロゴ・見出し・背景グラデーション・secondary barはすべて素材感のないフラットUIで、粘土世界の視覚言語と無関係。最初の一瞥（カードに焦点が合う前）は「クリーム色グラデーション＋中央寄せsans-serif」＝汎用SaaSランディングのパターンと同じ。
3. **中央揃え・均等余白の構成が「落ち着き／wellness」を演出してしまう。** ロゴ→見出し→カード→barが上から順に、等間隔・左右対称に並ぶ。これは瞑想アプリやヘルスケアSaaSが「読みやすさ・安心感」のために使う構成であり、flyerやゲームタイトル画面が使う非対称・傾き・はみ出し・オーバーラップによる「勢い」とは逆方向。
4. **画面全体に素材の凹凸・厚みがない。** 角丸カード＋薄いshadow＋pill形ボタン——これはEdTech/銀行/瞑想アプリ全般で使われる「汎用モダンアプリ」の語彙そのもの。写真1枚を除けば、太い縁取り・不揃いなカード形状・重なりのある立体感・ステッカー的な要素など、「手作りジオラマ」を思わせる要素が皆無。
5. **タイポグラフィが「大人向けアプリ」の仕事をしている。** 見出しは太字だが、白い柔らかいtext-shadowで縁取られた、上品なライフスタイルアプリ見出しの処理。色・輪郭・傾き・単語間の強弱変化がなく、"JIBUN CHOICE"も"今日は、どこ行く？"も、フィンテックのオンボーディング画面と同じ抑制されたタイポグラフィ的判断（weight・tracking・可読性用shadow）で扱われている。

## 2. 各専門家レビュー

### Game Designer — 「ゲームの入口に見えるか？」
最初の3秒：ロゴ→静的に見える見出し→小さいPLAY三角のついた写真、の順で読む。呼吸アニメーション(4.5s)とsparkle(2.6s)はあるが控えめで、「世界が今動いている」感には届かない。画面は「今、何かが起きている」合図（新着イベント・変化・「！」）を出しておらず、パンフレット写真的。背景でぼかされているのは実はContinuous World本体だが、靄化されたことで「もっと大きな世界がある」というcuriosityの手がかりとして機能していない。タップ対象は明快（読解不要）だが、「なぜ押したくなるか」のフックがない。**判定: 入口として機能はするが、期待感を煽るタイトル画面ではなくメニュー入口。**

### Kids UX Designer — 「10〜12歳が自分向けだと思えるか？」
フォント（角ゴシック太字）は幼すぎない。情報量は最小限で年齢的に適切（ロゴ・見出し・主CTA・副CTAのみ、過積載なし）。CTAの明快さ・タップ領域（250px高の全幅カード）は良好。一方、配色（クリーム／茶／オリーブの落ち着いた靄）は10〜12歳が普段ゲーム・アプリで見る高彩度な配色よりも、大人のwellness/教育トーンに寄っている。視線誘導はロゴ→見出し→カード→barの一直線で安全だが単調——ゲームらしい画面は世界（絵）を先に見せて型を後から乗せることが多い。**判定: 幼稚でも怖くもないが、視覚的な「テンション」が大人の「きれい」の基準で調整されている。**

### Art Director — 「これまでのJIBUN CHOICEと同じ作品に見えるか？」
画面上で唯一「JIBUN CHOICE」に見える要素は主カードのtown-center crop（正しくオンモデル：暖色・ミニチュアスケール・立体感）。問題はそれだけが浮島化していること——周囲（背景wash・タイポグラフィ・pill bar・shadow）はclay/dioramaと無関係な「ニュートラルなiOS的UIクロム」。背景のぼかし処理は技術的には正しく（新規生成なし、承認済み画像の非破壊再利用）誠実だが、結果として鮮やかなdiorama画像を汎用的なパステルグラデーションへ変換してしまっており、「世界観の拡張」ではなく「世界観の希釈」になっている。街頭チラシが持つはずのフラットな彩度の高い色面・太い縁取り・「切り紙／ステッカー」的なフレーム処理が画面のどこにも翻訳されていない。**判定: 素材単体はオンブランド、画面全体としてはオフブランド。**

### Mobile UI Designer — 375px portrait
構成は厳格な単一カラム中央揃え（ロゴ→見出し→カード→bar）、上下に`8dvh`/`10dvh`の余白。読みやすさ・タップ領域の安全性は高いが、見出し上部の靄部分（画面上部30〜35%程度）は完全に無機能な「死んだ空間」。階層はサイズでは主カード＞barと明確だが、見出し(24px/800)とカードタイトル(23px/800)がほぼ同じweight/サイズで並んでおり、「どちらが画面の主役か」で視覚的に競合している。タイポグラフィは11〜24pxの狭いレンジに単一fontファミリーが並ぶだけで、サイズ以外の階層演出（色・傾き・素材差）がない。密度は適切に低い（散らかっていない）。**判定: 技術的には堅実なモバイルレイアウトだが、視覚的には単調——カード以外に二度見したくなる要素がない。**

### Independent Design Critic
これは教科書的な汎用SaaS/wellnessアプリのデザインである：淡いグラデーション背景＋中央揃え太字見出し＋角丸shadowカード＋pill型副ボタン。「社会を冒険する」を「Start your meditation」に差し替えても同じレイアウトがそのまま成立する——Human Reviewが指摘した問題を構造的に裏付ける結果。secondary barのpill形状は「しごと図鑑（本・図鑑）」を意味する形ではなく、あらゆるアプリの「設定行」に使われる形——「主CTAより弱く見せる」ための消去法的選択であり、意味を持たない形状。主カード・secondary bar共に同じ`--radius`/`--shadow`トークンを画一適用しており、「何でも角丸カード化」というAI生成デザインの典型的な兆候。背景グラデーションは何も表現していない装飾（空でも特定の場所でもない）——意味のないgradientの典型例。**警告**: どの方向を選んでも「もっと賑やかに＝色を増やす／飾りを足す」への過修正は禁物——直すべきは装飾量ではなく「素材」（汎用アプリ素材→diorama固有の素材・非対称性）。**評価すべき点**: 情報構造自体は無駄がなく（CTA1つ＋副次1つ、偽のgamification要素なし）、この簡潔さはどの方向を選んでも維持すべき。

## 3. Visual Direction A / B / C

### A. WORLD IS THE HERO
- **一言コンセプト**: Continuous World全体を画面いっぱいの背景そのものにし、UIをその上に浮かせる。「もう世界の端に立っている」状態を最大化。
- **375pxでどう見える**: continuous-world.pngの鮮明な（ぼかさない）クロップが画面全体を覆う。テキスト可読性のための最小限の上下エッジ暗転のみ。ロゴは小さく上部に浮く。見出しは世界の絵の上に直接乗る強い縁取り/shadow処理。主CTAは「写真カード」ではなく世界の上に浮かぶボタン/タグへ変化（写真自体が既に背景なので、カードは冗長になる）。しごと図鑑は隅の小さいアイコンボタンへ縮小。
- **font**: 角ゴシック太字は維持するが、多彩な絵の上でも読めるよう縁取り強化やチップ背景など可読性処理を強化。
- **background**: continuous-world.png本体、鮮明・全面ブリード。
- **Continuous World**: 最大化——Homeが事実上Mapの開始カットのプレビューになる。
- **CTA**: 「写真カード」から「世界に重なる浮遊ボタン」へ。
- **しごと図鑑**: アイコンのみの隅配置へさらに格下げ。
- **長所**: 「世界に入る」感が最も強い。Home↔Mapの視覚連続性が最大（Homeそのものが Mapの最初のカットになる）。
- **リスク**: 賑やかな絵の上でのテキスト可読性リスク。主カードが持っていた説明的サブコピー（「まちへ出て、ゲームをする」）の置き場所が失われる。全端末アスペクト比で構図が破綻しないようクロップ調整の手間がかかる（新規art生成は不要だがposition調整の工数）。実行を誤ると「浮遊ラベル付き壁紙」に見えるリスク。

### B. GAME START
- **一言コンセプト**: Homeを明確なゲームタイトル画面として扱う。「今日は、どこ行く？」→PLAYへの一直線の勢いを作る。
- **375pxでどう見える**: 世界の絵は全面ブリードではなく、「扉／窓」のような輪郭（アーチ型や角丸の大きな窓）に収められた形で提示——広場を覗き見るような構図。窓の周囲は現在の淡いグラデーションではなく、既存パレットから取った彩度のあるフラットな色面（暖色系）——ゲームタイトル画面の「舞台」感を作る。見出しは窓の上に大きく配置。CTAは窓の下に独立した、大きく確信を持った「PLAY」的ボタン/バーとして提示（写真の上に重ねない）。
- **font**: 同じ角ゴシックだが、見出しと本文のサイズ差を今より大きく取り、タイトルロックアップらしく見せる。
- **background**: 写真ブリード/ぼかしをやめ、フラットな彩度の高い色面を「舞台」に。世界は窓の中でのみ鮮明に見せる。
- **Continuous World**: Aより footprint は小さいが、鮮明・非圧縮で「本物の場所を覗く」感が強い。
- **CTA**: 明確な独立した大型PLAYボタン/バー——写真キャプションではなく、ゲームメニューの「PLAY」に近い扱い。
- **しごと図鑑**: PLAYボタン下の小さなテキストリンク/アイコン行——「オプションメニュー」的な位置づけ。
- **長所**: 「これはゲームだ、押せば始まる」が最も明快（Game Designerの問いに直接応える）。窓型・色面構成は純粋なCSS/layoutで実現可能（新規合成不要）。
- **リスク**: 窓が小さすぎると世界の存在感が薄まる（十分に大きく取る必要あり）。強いフラット色面の導入はパレット判断そのもの——ブランドカラーブロックに寄りすぎるとdiorama感が失われ、モバイルゲームストアの汎用スプラッシュ画面に見えるリスクがある（窓の縁の不揃い感や層のある奥行きなど、diorama固有の素材感を伴わないと汎用化する）。

### C. PLAYFUL DIORAMA
- **一言コンセプト**: これまでのJIBUN CHOICEの街頭チラシに最も近い方向。太い縁取り・「切り紙／ステッカー」的な層・わずかに不揃いな手作り感・強弱のあるタイポグラフィを、写真1枚だけでなくUIクロム全体へ翻訳する。
- **375pxでどう見える**: 主カードに、単なる角丸+薄いshadowではなく、太めで少し不揃いな縁取り（ステッカーを切り出したような輪郭）、わずかな回転/オフセットによる「厳密に揃っていない手作り感」を付与。見出しタイポグラフィは一様な1行ではなく、強弱をつけた表現（例：「今日は、」を小さく＋「どこ行く？」を大きく太く、わずかな傾き）。背景の靄ぼかしをやめ、暖色のフラットな色または紙質感のような非写真的テクスチャへ変更——世界の一体感は「写真を薄めて壁紙化する」のではなく、UIクロム自体をdioramaの素材感に寄せることで作る。しごと図鑑はpill型barではなく、同じ素材言語の小さな「ステッカー／タグ」形状へ縮小。
- **font**: 角ゴシック太字は維持しつつ、フレーズ間のサイズ／傾きの強弱で手描き文字的な元気さを出す（新規フォント資産は不要、CSSのscale/rotate/letter-spacingのみ）。
- **background**: 写真ブリードではなく、暖色のフラット色または紙質テクスチャ。
- **Continuous World**: 現状通り主カード内のみだが、カード自体を「ページの上に置かれたdioramaオブジェクト／ステッカー」として再スタイル。
- **CTA**: PLAYのアフォーダンスを、丸い小アイコンではなく「チケット」や「道標」のようなdioramaらしい形状のボタンへ。
- **しごと図鑑**: 小さなステッカー/タグ——スケールでも素材感でも明確に副次的。
- **長所**: 既にHuman承認済みのチラシ・イベント制作物の視覚言語と最も直接的に連続（発明が最も少ない方向）。Art DirectorとIndependent Criticの核心的指摘（汎用アプリ的クロム）に最も直接的に応える——写真だけでなく画面全体がdioramaの素材を纏う。3案中「汎用アプリ化」への逆戻りリスクが最も低い。
- **リスク**: 3案中最もCSS/layoutの作り込み工数が大きい（不揃いな縁取り・層のあるshadow・表現的タイポグラフィいずれも「魅力的な手作り感」と「崩れて見える」の境界の調整が難しい）。抑制を誤ると「賑やかすぎる／装飾過多」（Independent Criticの過修正警告が最も当てはまる方向）。「不揃いだが整って見える」バランスが最も繊細——作り込み不足だと単に雑に見え、やりすぎると幼く見える。

## 5. 統合推奨案 — **C 65% + B 25% + A 10%**

- **土台（C, 65%）**: 画面全体のクロム（主カードの縁取り・shadowの層、見出しタイポグラフィの強弱、しごと図鑑のステッカー化、背景を写真ブリードから暖色フラット/テクスチャへ）をdiorama素材言語へ翻訳する。これが「汎用SaaS的に見える」問題の根（クロムそのもの）を直接修正する。
- **CTAの勢い（B, 25%）**: 見出し直後に続く、確信を持ったPLAY的CTAの配置ロジックを借用する。主イラストを「ページに置かれた写真カード」ではなく「dioramaらしい枠に収められた、世界を覗く窓」として扱うことで、Game Designerが求める「今にも始まりそう」な勢いを加える。
- **世界との連続性（A, 10%）**: 窓/枠の外側にごくわずかに世界がにじみ出る（枠の下や背後にちらりと覗く）ようにし、「この窓の外にもっと世界がある」という予感を軽く残す——背景全体を世界にする必要はない。
- この配合は情報構造（機能）を一切変えず、Independent Criticが指摘した「汎用アプリ的クロム」を根本から修正し、Game Designerの求める起動感も両立できる。

3. **タイポグラフィの表現度**: 見出しに「手描き的な強弱・傾き」（C）をどこまで許容するか——魅力的にも、崩れて見えるようにも転びうる、好みが分かれる可視化判断であり、実装前にHumanの目で確認したい。
