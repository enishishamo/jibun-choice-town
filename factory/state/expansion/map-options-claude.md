7/8/7/8/7/7/6/5/8/6 — 「島が増える」は増加自体のワクワクに直結。ただし既存の町と地続きでなく、visual continuity弱。

9/7/8/7/8/7/5/9/8/8 — 世界が「続いている」。既存town-heroが中心のまま。50worldでは地区内密度管理が必須。
## E. セマンティックズーム
8/9/7/6/5/5/3/6/5/7 — ピンチズームは低年齢に難、実装最重。
## F. 訪問開示（fog-of-war全面）
7/6/9/9/7/6/6/6/7/9 — 発見は最強だが初見の選択肢が乏しく「まず何を押すか」で迷う。

## Claude結論: D を基幹に、C の「増える感」と F の「靄と開示」を要素として吸収した hybrid
- 基幹: 連続座標の町世界。中心=既存town-hero。地区（えきまえ/うみべ/やまのて/こうがい/もり…）が
  方角に地続きで生える。カメラは1軸パン（モバイル横スワイプ）＋地区チップでスムーズスクロール。
  画面遷移で世界を切らない（「世界の中を見ている」感覚の維持）。
- C要素: 新worldが増える＝地区に建物・出来事が「増築」される。地区自体も増える（増えることがワクワク）。
- F要素: 未開示地区は端に靄＋シルエット＋気配（🚧/煙/鳥）で「まだ知らない場所がある」を常時提示。
  ただし初期状態でも中心街＋1地区は開いており、初見で迷わない。
- WHY_TAP_NEXT: 「画面の端に、靄のかかったシルエットと動く気配が見えている」＋
  「訪れた場所は建物が完成し、旗や住民の変化が起きる」。押す理由が地図の絵の中にある。
- 最大リスク: パン迷子と地区内hotspot密度。緩和: 地区チップnav常設＋generic layout system
  （district内slot自動配置・衝突回避）＋1地区あたりworld上限（6-8）で新地区を自動増設。
