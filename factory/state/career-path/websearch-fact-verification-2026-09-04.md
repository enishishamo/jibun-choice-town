# Career Path Fact QA — WebSearch実地検証記録（2026-09-04）

## 背景

Codex plausibility review（訓練知識ベースのみ、インターネット非接続）を6round
実施したが、毎round新しい指摘が出続け非収束だった（詳細:
`fact-review-result-r2.json`〜`fact-review-result-r6.json`、および memory
`codex-reviewer-calibration.md` の2026-09-04追記）。ユーザー裁定により、
Codex round を繰り返すのではなく、**現在の日本の公的・一次情報をWeb検索で
直接検証する**方式に切り替えた。

対象は62職業すべての再調査ではなく、過去6roundで
「未解決／低確信／round間で指摘が揺れた／資格・学歴・法制度を誤ると問題が
大きい」ものを優先。4体のAgent（general-purpose、WebSearch使用）に分担させ、
全17職業・22論点を検証した。

## PUBLIC BLOCKER判定

このラウンドの実地検証で見つかった項目は、修正前の状態では以下がPUBLIC
BLOCKER相当だったと判断する（子どもに実際に誤った資格・進路情報を伝える
リスクがあったもの）:
- doctor: 高校required矛盾、臨床研修の範囲誤り
- labtech: 業務独占資格の誤表記
- nurse: 准看護師ルートの実務経験のみで受験可能という誤り
- river-operator / env-measurer: 施設単位の任意的義務を個人必須資格のように誤解させる表現
- incinerator-operator / landfill-manager: 講習コース名を法定資格名として扱っていた
- food-inspector: 任用資格の複数要件構造の欠落・国家公務員試験の受験資格誤り
- logistics: 運転免許が不要であるかのような誤表記
- crowd-safety: 配置基準の説明不足（「個別判断」という誤解を招く表現）
- trip-conductor: 資格の要否を規模基準と誤って説明
- forest-picker: 中学校卒業を前提とする誤り

**これらはすべて2026-09-04時点で修正済み。修正後の再検証（62職業sweep・
tsc・flow bot regression）はPASS。よって CAREER_FACT_PUBLIC_BLOCKERS = 0
と判定する。**

パンダ・pharmacist・dietitian（学校種別）・forest-feller・crowd-safety
（2級受験資格）は検証の結果「既存データは実は正確だった」ことが判明した項目
であり、修正は不要（もしくは表現強化のみ）。
