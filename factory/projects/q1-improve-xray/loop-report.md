## 3ステートメント（再設計後）

- **CORE LOOP**: 依頼票の原理を読む → 目の前の患者（体格・姿勢が毎回違う）を見てフレームの位置×サイズを決める → 呼吸を読んで撮る → うつった画像を自分の目で判定して届けるか撮り直すか決める。考えどころは「この患者ならどの範囲か」「いつ押すか」「この写りで診断できるか」
- **MASTERY**: 上級者は患者を見ただけで最小コストのフレームを選び、X線1〜2回・差し戻しゼロで届ける（perfect判定）。初心者はLに頼って被ばくを倍にするか、切れた画像を先輩に差し戻される
- **REPLAY**: 体格3×姿勢3×症例3＝27通り。呼吸の開始位相もランダム。失敗すると新しい患者になり暗記が通用しない
- **NOVICE VS EXPERT**: 上級者は「大きなからだは大きく写る」「フレームは姿勢に合わせる」という原理を新しい患者へ転移でき、L頼み（コスト2倍・位置は結局読む必要がある）から卒業する

## 修理で潰した exploit（Codex adversarial 指摘 → 対応）

1. 常時L@まんなか支配戦略 → L の縦幅を縮小し**位置一致必須**に（blind L は56%止まり・失敗時は予算全損）
2. 提出ボタンのオラクル化 → 差し戻しをmisjudgeカウント化（1回目は理由を教えない・3回で症例失敗）
3. メモ画面が未clip全身を表示 → 実際に届けた clip 画像で判断
4. 呼吸サイクルの暗記 → 開始位相ランダム化
5. 技師が診断を断定する文言 → 「写っていた」へ（診断は医師の本分）

## 残課題（MEDIUM・次回改善候補）

- L+正しい位置は全症例をカバー（体格判断はperfect判定にのみ効く）→ 予算/演出での追加差別化余地
- ALARA の「L=2回ぶん」は単純化（実際は照射体積・散乱線の問題）→ 学習上は許容、注記済み
- 画質判定が二値的（切れ/ブレ）→ 「うっすら」等の中間品質は将来拡張
