# night-port 「真夜中のみなと」設計（v1）

Event: 真夜中、きみの家に届く荷物が船から下ろされている。
World flow (research準拠): プランナーが揚げ順と仮置きを決める → クレーンが下ろす →
検数員が書類と現物を照合 → 通関の許可後、配車がまちへ届ける。
安全原則（research safety_sensitivities）: 速さと安全が衝突したら「停止・確認」が正解。
夜を冒険として美化しない（照明・無線・立入管理が前提の職場として描く）。

## Q1-1: yard_plan（ヤードプランナー）gameType: yard_plan
- Goal: 船から下りる8個のコンテナを、ヤード3列（+リーファー電源列+危険物区画）へ仮置きする。
- C: TOSの搬出予定表（各箱の引取日 1/2/3日目）＋箱の属性（40ft背高/リーファー/危険物）＋ヤードのきまり
  （下の箱を先に出すと積み替え=リハンドルが発生・リーファーは電源列のみ・危険物は隔離区画のみ）。
- D: 引取日を読んで「早い箱を上に・遅い箱を下に」。属性制約は機械強制（電源のない列への
  リーファーは作業員が首を振る）。列の埋めすぎ（深さ3超）不可。
- 失敗: 夜明けの搬出シミュレーションでリハンドル4回以上 → 朝のトラックが待たされゲート渋滞、
  先輩と組み直し。retry=新しい船（属性・引取日再抽選）。
- Mastery: リハンドル0（=引取順の完全な先読み）。世界フィードバック: 置くたび列が視覚的に積み上がり、
  搬出シミュレーションで箱が1つずつ出ていき、リハンドルの瞬間は箱が横へ移される演出＋❗。
- 参照原理: Mini Metro/倉庫番系「あとで取り出す順を先に読む」空間パズル。

## Q1-2: crane_lift（ガントリークレーン運転士）gameType: crane_lift
- Goal: 6回の吊り作業を安全に完了する。1吊りごとに 計器盤（風速計・ロック表示・地上合図）を読み、
  「おろす / ゆっくり(減速) / 停止して確認 / 今夜は中止」を選ぶ。
- C: 運用規程カード（風速: 10m/s超は減速・16m/s超は中止＝施設規程・ロック4点未満は吊らない・
  合図と指示が食い違ったら停止して確認）＋毎回の計器値。
- D: 規程×今の計器の照合＋「不要な停止はスケジュール遅延」のトレードオフ
  （babyの過剰反応罰と同型: 正常時に停止を繰り返すと船が遅れ、良判定を逃す）。
- 機械強制: ロック不完全で「おろす」→ 吊り上げ前に安全装置が作動し即日終了（事故は起こさせない）。
  合図不一致で続行→ 作業指揮者が非常停止（大失点）。16m/s超で続行→ 中止命令。
- 失敗: 安全装置/非常停止2回で夜間作業交代。retry=別の夜（風パターン・事象再抽選）。
- Mastery: 全6吊り正判定＋不要停止0。世界FB: 風速計の針が動き、コンテナが船→トレーラーへ
  移動するアニメ、非常停止は赤ランプ点灯。
- 参照原理: 「停止する勇気」justified_refusal（debut/curbで実証済みの型を安全領域へ翻訳）。

## Q1-3: tally_check（検数員）gameType: tally_check
- Goal: 5個のコンテナを受け渡し照合する。1箱ごとに 書類（番号・封印番号・個数）と現物
  （番号・封印・外観）を見比べ、「正常受け / 番号を照会 / 封印を照会 / 損傷を記録」。
- C: タリーシート＋書類。コンテナ番号のチェックデジット（末尾1桁が検算数字＝1文字違いを
  見抜ける根拠）は「検算ずみ✓/？」表示として提供（計算はさせない・小4配慮）。
- D: 3点照合（番号/封印/外観）。損傷は「いつついたか断定しない」＝損傷記録の文言選択
  （「今回の荷役でついた」を選ぶと公正性違反で差し戻し）。
- 機械強制: 差異があるのに正常受け→ 荷主側記録と食い違い、照会が返ってくる（ミス予算2）。
  全部照会スパム→ 夜の荷役が止まり船長から苦情（正常箱の照会は罰）。
- Mastery: 5箱ノーミス。世界FB: 照合ずみの箱がゲート通過列に並んでいく（curbの街路ストリップ型）。
- 参照原理: Papers, Please の多書類照合を「公正な第三者の記録」へ翻訳。

## Q1-4: truck_dispatch（配車担当）gameType: truck_dispatch
- Goal: 朝いちばんの4本の配送を、3台の車両（普通シャーシ2・背高対応低床1）へ割り当てる。
- C: 配車表（各コンテナ: サイズ/背高/重量/納入予約時刻/行き先ルートの高さ制限）＋車両条件
  （背高40ftは低床シャーシのみ・ルートBは高さ3.8m制限=背高不可・重量24t超は不可）。
- D: ハード制約（機械強制: 背高×普通シャーシは配車係が首を振る）＋ソフト最適化
  （近い行き先を同じ車の連続運行に=空走削減。予約時刻に間に合わない組合せは差し戻し）。
- 失敗: 予約遅れ2件で朝の便が崩れ、ベテランが組み直し。retry=別の朝。
- Mastery: 全部時刻内＋空走最小。世界FB: 割当てるとトラックに箱が載り、出発順に並ぶ。
  時刻超過はゲートの時計が赤くなる。
- 参照原理: Overcooked的「同時制約下の割当」を輸送制約へ翻訳。

## 共通
- 数値正本は src/q1/portLogic.ts。UIはミラー（機械強制はロジック側）。
- Language: 専門語は ｜荷役《にやく》・｜蔵置《ぞうち》・｜検数《けんすう》 を採用
  （初出ルビ+15-30字言い換え）。ボタンは2-6字。失敗文は答えを漏らさない。
- Art: scene-port（夜の連続シーン）+ ba-before(静かな夜のふ頭)/ba-after(朝、荷物が街へ) の3点。
- 非重複: 積み上げ先読み(yard)はpit(均質化目的)と目的が異なる。照合(tally)はcurb(ルール判定)と
  異なり「書類と現物の同一性証明」。craneはgas(時間予算)と異なり停止自体が正解になる。
