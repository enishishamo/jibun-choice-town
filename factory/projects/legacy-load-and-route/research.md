## 1. 学校給食の配送に関わる仕事（実務主体は仮置き）

学校給食の食材配送は、自治体（給食センター）が委託する配送業者、または
給食センター職員が担う。契約形態は自治体ごとに異なり、本リサーチで確認した
大川市の例では「配送業務の受託者」に委託されている。

- 実務主体: 「学校給食センターの配送業務に関わる仕事」（委託業者の運転手・
  補助作業員、または給食センター職員 — 自治体により異なるため職名は断定しない。
  `FACT_CHECK_REQUIRED`: JIBUN CHOICEのゲーム上の職業名表記をどう置くか）
- 働く場所: 学校給食センター〜配送車内〜各学校の配膳室
  （出典: 大川市学校給食センター給食配送業務仕様書）
- 達成すること: 調理済み・仕入れた食材/調理済み給食を、決められた温度帯を
  保ったまま、各学校の受け入れ時刻（検収・配食）に間に合うように届けること
- 制約:
  - 学校給食衛生管理基準（文部科学省告示第64号）およびHACCPの考え方に
    基づいた温度管理・記録義務
  - 大量調理施設衛生管理マニュアル（厚生労働省）に基づく原材料の保存温度基準
  - 契約上の業務時間帯（例: 大川市の仕様書では午前9:30〜午後3:30が原則）
  - 車両積載量・コンテナ重量の制限（大川市の例: コンテナ1台500kg以内、
    車両積載能力2t以上）
- よくある失敗: 温度帯を誤って荷室（コンテナ・保冷庫）に積む／到着が遅れて
  受け入れ側の時間枠に間に合わない／遅延が発生したのにセンターへ連絡しない
  （大川市仕様書 8条③: 「予定到着時刻に遅れる事由が発生した場合等には、
  速やかにセンターに連絡し、指示を仰ぐこと」）
- 判断の結果どうなるか: 温度基準を外れた食材は学校側の検収（受け入れ検査）
  で不適合となりうる／到着遅延は給食提供時刻に直結する
- 連携相手: 給食センターの配送計画担当、各学校の検収責任者（栄養教諭・
  学校栄養職員等）、調理従事者
- 一人では決められないこと: 配送・回収計画そのもの（センター側があらかじめ
  定める）、緊急時の経路変更の最終判断（センターの指示を仰ぐ）
- source:
  - 学校給食衛生管理基準（文部科学省告示第64号、平成21年3月31日）
    https://www.mext.go.jp/b_menu/hakusho/nc/__icsFiles/afieldfile/2009/09/10/1283821_1.pdf
  - 大量調理施設衛生管理マニュアル（厚生労働省、最終改正: 平成28年10月6日
    生食発1006第1号）
    https://www.mhlw.go.jp/file/06-Seisakujouhou-11130500-Shokuhinanzenbu/0000139151.pdf
  - 学校給食センター給食配送業務仕様書（大川市教育委員会）
    https://www.city.okawa.lg.jp/s077/010/020/010/050/020/2siyou1108.pdf

## 2. 判断①: 食材ごとの保存温度帯マッチング（C⇄D の核）

### C: 見る・使う情報 — 実在する保存温度基準

出典: 大量調理施設衛生管理マニュアル（厚生労働省）別添1「原材料、製品等の
保存温度」。原文の表をそのまま書き出す（℃は原文どおり）。

| 食品名 | 保存温度 |
|---|---|
| 穀類加工品（小麦粉、デンプン）、砂糖 | 室温 |
| 食肉・鯨肉、食肉製品、鯨肉製品 | 10℃以下 |
| 食肉・鯨肉を凍結したもの、冷凍食肉製品、冷凍鯨肉製品 | -15℃以下 |
| ゆでだこ、魚肉ソーセージ・魚肉ハム・特殊包装かまぼこ | 10℃以下 |
| 冷凍ゆでだこ、冷凍魚肉ねり製品、冷凍食品全般 | -15℃以下 |
| 生食用かき | 10℃以下 |
| 生食用冷凍かき | -15℃以下 |
| 液状油脂 | 室温 |
| 固形油脂（ラード、マーガリン、ショートニング、カカオ脂） | 10℃以下 |
| 殻付き卵 | 10℃以下 |
| 液卵 | 8℃以下 |
| 凍結卵 | -18℃以下 |
| 乾燥卵 | 室温 |
| ナッツ類、チョコレート | 15℃以下 |
| バター、チーズ、練乳 | 15℃以下 |
| **生鮮果実・野菜** | **10℃前後** |
| **生鮮魚介類（生食用鮮魚介類を含む）** | **5℃以下** |
| 乳・濃縮乳、脱脂乳、クリーム | 10℃以下 |
| 清涼飲料水 | 室温 |

重要な発見（既存実装との差分）:

- **生の魚（さば等）は5℃以下、生の食肉（とり肉等）は10℃以下** —
  「魚介類」と「食肉類」は同じ「冷蔵」枠にまとめてよいものではなく、
  基準表の上では別の温度が定められている。既存ゲームは両方を1つの
  「冷蔵5℃」荷室に入れる設計だったが、一次資料上は魚介類のほうが
  厳しい温度基準（5℃以下）で、食肉は10℃以下である。
  → 新ゲームでは「同じ冷蔵でも魚の方がシビア」という実務上の
  ニュアンスをC情報として出せる（`FACT_CHECK_REQUIRED`: 実際の
  給食センターの運用上、両者を同一の冷蔵コンテナで運んでいるか、
  分けているかは未確認。基準表は「保存温度の下限要求」であり、
  実運用でのコンテナ区分の粒度は別途確認が必要）。
- **冷凍コロッケ等の冷凍食品は -15℃以下**（既存実装の-18℃固定とは
  基準表の数値が異なる。表では「冷凍食品」は-15℃以下、「殻付き卵の
  凍結卵」のみ-18℃以下。既存実装の-18℃という数値の根拠は不明
  → `FACT_CHECK_REQUIRED`）。
- **生鮮野菜（じゃがいも等）は「10℃前後」であり、冷蔵庫（10℃以下の
  枠）と同じではない** — 表の書き方は「10℃前後」で、他の食品群の
  「○℃以下」という上限指定と書き方が異なる。過度な低温もむしろ
  望ましくない、という含みがある。

### 低温障害・低温糖化（じゃがいもを深く冷やしすぎない理由）

- 農林水産省「食品事業者ができること」（アクリルアミド低減の取組み）:
  ばれいしょ（じゃがいも）は **8℃以上** で保存することが望ましいとされる。
  低温（8℃未満）で長期保存すると「低温糖化」が起こり、還元糖濃度が
  上がる。これは加熱調理（揚げる等）時のアクリルアミド生成量増加に
  つながるため、低温保存を避けるべきとされている。
  出典: 農林水産省「食品中のアクリルアミドを減らすための取組
  （食品事業者ができること）」
  https://www.maff.go.jp/j/syouan/seisaku/acryl_amide/a_syosai/teigen/zigyosya.html
  （`FACT_CHECK_REQUIRED`: このページはアクリルアミド低減という食品
  「品質」の観点の資料であり、食中毒予防のための衛生基準ではない。
  「じゃがいもを冷凍・強い冷蔵に入れると失敗」というゲーム上の理由づけ
  としては、衛生基準ではなく品質劣化の理由として書くのが正確）
- 一般消費者向け情報（管理栄養士監修記事等、二次情報）では、じゃがいもは
  2〜4℃程度の低温で保存すると変色・低温障害を起こすとされるが、これは
  一次資料（農水省・厚労省）で確認できておらず `FACT_CHECK_REQUIRED`。

### D: 判断・操作（この場面でプレイヤーが行うべきこと）

- 各食材を、上記の温度区分（例: 常温／冷蔵10℃以下／冷蔵5℃以下／
  冷凍-15℃以下）のうち正しい荷室・コンテナへ割り振る
- 単純な「肉・魚=冷蔵、それ以外=常温か冷凍」の二択ではなく、
  同じ「冷蔵」に見えても魚と肉で厳しさが違う、じゃがいものような
  野菜は冷やしすぎるとかえって良くない、という**カテゴリ内の細分化**を
  読み取って判断する必要がある
- 10-12歳向けに削るべきもの: 別添1の全項目（穀類加工品〜清涼飲料水まで
  約20カテゴリ）をそのまま出す必要はない。給食で扱う実際の食材
  （生魚・生肉・冷凍食品・野菜・卵・乳製品・パン等常温品）に絞り、
  5〜8カテゴリ程度のプールに圧縮するのが妥当

## 3. 判断②: 複数校への配送順序と締切（C⇄D の核）

### C: 見る・使う情報 — 実在する時間制約

1. **調理後2時間以内に給食提供**という全国共通の基準:
   - 学校給食衛生管理基準（文部科学省告示第64号）第2 学校給食施設及び
     設備の整備及び管理に係る衛生管理基準 (2)①四:
     「共同調理場においては、調理した食品を調理後２時間以内に給食
     できるようにするための配送車を必要台数確保すること。」
   - 同基準 第3 調理の過程等における衛生管理に係る衛生管理基準
     (5)配送及び配食 ①配送 一、④食品の適切な温度管理等 五:
     「調理後の食品は、適切な温度管理を行い、調理後２時間以内に
     給食できるよう努めること。また、配食の時間を毎日記録すること。」
   - 大量調理施設衛生管理マニュアル（厚生労働省）4(4):
     「調理後の食品は、調理終了から２時間以内に喫食することが
     望ましい。」
   - 出典URL（2件とも上記1.のsourceと同一）
2. **配送過程の温度管理義務**（学校給食衛生管理基準ではなく大量調理施設
   衛生管理マニュアル4(3)③): 「配送過程においては保冷又は保温設備の
   ある運搬車を用いるなど、10℃以下又は65℃以上の適切な温度管理を
   行い配送し、配送時刻の記録を行うこと。」→ 配送中も温度と時刻の
   記録が実務として発生する
3. **検収は学校側（検収責任者）の仕事であり、配送員自身の仕事ではない**:
   学校給食衛生管理基準 第3 (3)食品の検収・保管等 一:
   「検収は、あらかじめ定めた検収責任者が、食品の納入に立会い、
   品名、数量、納品時間、納入業者名…品温（納入業者が運搬の際、
   適切な温度管理を行っていたかどうかを含む。）…について、毎日、
   点検を行い、記録すること。」
   → 配送員の役割は「時間内に、正しい温度を保って届けること」で
   あり、「検収そのものを行う」わけではない。ゲーム上、配送員が
   検収する設計にすると実務主体を誤らせる。
4. **実際の配送業務の枠組み**（大川市の仕様書、自治体固有の運用のため
   全国共通の基準ではない点に留意）:
   - 車両1台につき運転手・補助作業員の2名体制
   - 1日の配送・回収計画はセンターが事前に定める（配送員が経路を
     ゼロから決めるわけではないが、実際に運転して各校を回る順序に
     従って行動する）
   - 業務時間は原則午前9:30〜午後3:30（この自治体の契約条件であり
     全国一律ではない）
   - 遅延が発生しそうな場合は速やかにセンターへ連絡し指示を仰ぐ
     （＝締切に間に合わない見込みが生じた時点でエスカレーションする
     という実務上の判断が実在する）
   - 出典: 大川市学校給食センター給食配送業務仕様書（大川市教育委員会）
     https://www.city.okawa.lg.jp/s077/010/020/010/050/020/2siyou1108.pdf

`FACT_CHECK_REQUIRED`: 「2校のうちどちらを先に回ると間に合わなくなるか」
という具体的な移動時間・距離の数値は、公開資料からは確認できなかった
（配送・回収計画は各センターの内部資料で、大川市仕様書でも「別紙1」
「別紙2」として非公開の別添扱いになっている）。したがって、ゲーム内で
使う具体的な「A校まで15分、B校まで25分、B校の締切は調理終了後90分」
といった**数値そのものは実在資料からの引用ではなく、リサーチで確認した
制約構造（=調理後2時間以内に全校へ届ける必要がある／校ごとに実際の
検収・配食開始時刻は異なりうる／先に回る学校の選択が後の学校の到着に
影響する）を土台にしたゲーム内の仮設定**として扱う必要がある。
fact_sheet.jsonにその旨を明記すること。

### D: 判断・操作（この場面でプレイヤーが行うべきこと）

- 「調理後2時間以内」という全体の締め切りの中で、複数校（2校以上）を
  訪問する順序を選ぶ
- ある学校を先に訪問すると、移動時間の分だけ次の学校への到着が遅れる
  ため、片方の締切（2時間ルールや学校固有の受け入れ時刻）を破る
  リスクが生じる、というトレードオフを読み取る
- 到着が遅れそうな場合にセンターへ連絡する、という実務のエスカレーション
  行動をゲーム上のフィードバックに反映できる（「間に合わなかった」で
  終わらせず、実務上は連絡・調整が発生することを示せる）
- 10-12歳向けに削るべきもの: 実際の検収の記帳項目（品名・数量・
  ロット番号等）、正式な経路最適化アルゴリズム、車両やコンテナの
  工学的仕様。ゲームでは「各校の締切に対して、移動時間の合計が
  間に合うかどうか」という比較判断だけに絞る

## FACT_CHECK_REQUIRED 一覧

1. この職の実務主体（委託業者の運転手なのか、給食センター職員なのか）は
   自治体により異なる。ゲーム上の職業名表記をどう置くか要確認。
2. 「魚介類と食肉類を同じ冷蔵コンテナで運ぶか、分けるか」という実運用の
   粒度は、基準表（保存温度の下限要求）からは分からず、給食センターの
   実際のコンテナ運用を別途確認する必要がある。
3. じゃがいもの「低温障害」的な扱いの一次資料は、食中毒予防の基準
   （厚労省・文科省）ではなく、農水省のアクリルアミド低減資料
   （品質劣化の観点）のみ確認できた。消費者向け記事にある「2〜4℃で
   変色する」という具体的な低温障害の数値は一次資料で未確認。
4. 既存実装（`LogisticsGame.tsx`）が使っている冷凍-18℃という数値の
   根拠は、大量調理施設衛生管理マニュアル別添1の「冷凍食品-15℃以下」
   とも「凍結卵-18℃以下」とも一致しない。どちらを新ゲームの基準にするか、
   または既存の-18℃の出典を別途探す必要がある。
5. 2校間の具体的な移動時間・各校の受け入れ締切時刻の実数値は、
   自治体内部の配送・回収計画（非公開）に属し、一次資料からは
   確認できなかった。ゲーム内で使う具体的な分数はリサーチに基づく
   仮設定であり、実在資料からの引用ではないことをfact_sheet.jsonに
   明記すること。
